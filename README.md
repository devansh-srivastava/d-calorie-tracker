# Apex Health

Personal F1-inspired nutrition, training, and weight dashboard.

The app runs locally by default and keeps an offline copy in browser storage. To connect it to the companion Google Sheet, copy `config.example.js` to `config.js`, add the deployed Apps Script `/exec` URL and secret, then publish the site. `apps-script.gs` contains the API handler for the four tracker tabs.

Google Sheet: https://docs.google.com/spreadsheets/d/17lzS3rXa1KKh34Cr9HJJsrplEb_TBbbr__C21FQLvJc/edit
